

## 本项目的讲解重点
这个项目不是单一的“调用一次大模型”，而是一个完整的 AI 应用：

- FastAPI 负责对外提供 HTTP 接口
- LangChain 负责模型调用、会话记忆和工具能力
- LangGraph 负责约会行程的状态编排
- LlamaIndex 负责情感咨询的书籍索引和检索
- Redis 负责情感咨询的会话记忆
- Chroma 负责书籍向量存储
- Tavily 和高德地图负责外部信息获取
- ReportLab 负责恋爱报告 PDF 输出

所以讲课时要抓住一条主线：

> 用户输入 -> 后端编排 -> 外部检索/知识召回 -> 模型生成 -> 结构化输出
